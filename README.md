O ETECRead é um acervo digital desenvolvido com o objetivo de modernizar e facilitar o acesso ao catálogo da biblioteca. O sistema funciona como um CRUD completo, contando com dois níveis de acesso: administrador e usuário.

O administrador é responsável pelo gerenciamento do acervo, podendo cadastrar, editar e remover livros, além de controlar informações relevantes do sistema. Já o usuário pode consultar os livros disponíveis, visualizar detalhes das obras e agendar uma data para retirada do livro na biblioteca física, otimizando o atendimento e a organização do acervo.

O projeto, entretanto, não se encontra totalmente finalizado. Algumas funcionalidades importantes ainda não foram implementadas, principalmente nas camadas de segurança, como recuperação de senha, autenticação em dois fatores (2FA) e soft delete. Além disso, a área do usuário pode ser aprimorada com a inclusão de filtros mais avançados para pesquisa e navegação do acervo.

Mesmo incompleto, o sistema estabelece uma base sólida para futuras melhorias, demonstrando a aplicação prática de conceitos de desenvolvimento web, organização de dados e controle de acesso.
